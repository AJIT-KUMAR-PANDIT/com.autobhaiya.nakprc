# Pages Documentation

This directory contains the page components for the application.

## List of Pages

- **Home.jsx**: The landing page of the application (Route: `/`).
- **Payments.jsx**: The payments section (Route: `/payments`).
- **Profile.jsx**: The user profile page (Route: `/profile`).

## Usage

These pages are routed in `src/App.jsx`. To add a new page:

1. Create a component in `src/pages`.
2. Import it in `src/App.jsx`.
3. Add a `<Route>` within the `<Routes>` component.
